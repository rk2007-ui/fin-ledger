# 💰 Fin Ledger — AI Financial Advisor

A beautiful AI-powered personal finance advisor built with Streamlit and Google Gemini.

## Features
- 📊 Budget Calculator (50/30/20 rule)
- 💳 Debt Payoff Calculator
- 🎯 Savings Goal Tracker
- 📈 Investment Advisor

## Deploy to Streamlit Cloud (Free)

1. Upload this folder to a **GitHub repository**
2. Go to **share.streamlit.io**
3. Sign in with GitHub
4. Click **"New app"**
5. Select your repository
6. Set main file: `app.py`
7. Click **Deploy**
8. Enter your Gemini API key in the sidebar

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Get Gemini API Key
1. Go to aistudio.google.com
2. Click "Get API Key"
3. Create a new key
4. Paste it in the app sidebar
